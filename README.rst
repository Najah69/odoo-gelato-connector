Integrates `Gelato <https://www.gelato.com>`_ Print-on-Demand fulfillment into
Odoo's sales workflow. Operators or customers submit print orders (posters,
framed prints, canvases, mugs, …) directly from Odoo; Gelato handles worldwide
production and shipping.

Features
--------

* One-click order submission to Gelato from backend or customer portal
* Real-time status updates via HMAC-SHA256 verified webhooks
* Hourly cron fallback for missed webhook events
* Automatic ``sale.order`` and invoice creation per product mapping
* Customer portal: order history, tracking link, new order form
* Multi-company support with per-company API configuration
* Test / Production environment switch

Requirements
------------

* Odoo 16, 17 or 18 (Community or Enterprise)
* Python package ``requests`` (included in standard Odoo images)
* A `Gelato account <https://www.gelato.com>`_ with API access enabled
* Images hosted at a publicly accessible HTTPS URL

Installation
------------

Add the repository to your ``addons_path``::

    git clone https://github.com/Najah69/odoo-gelato-connector.git

Then update the apps list and install **Gelato Print-on-Demand Connector**.

Configuration
-------------

1. Go to **Sales › Gelato › Configuration** and create a record:

   * Paste your Gelato API key (from dashboard → Settings → API).
   * Set **Environment** to *Test* during setup, *Production* when live.
   * Optionally paste the webhook secret generated by Gelato.

2. Go to **Sales › Gelato › Product Catalogue** and map your products:

   * Fill in the Gelato ``productUid`` (find it in the Gelato catalogue browser).
   * Optionally link an Odoo service product to trigger automatic invoicing.

3. Register the webhook in the Gelato dashboard:

   * URL: ``https://<your-domain>/gelato/webhook``
   * Event: ``order_status_updated``

Usage
-----

**From the backend**

Open *Sales › Gelato › Print Orders → New*, fill in the customer, image URL,
and product, then click **Send to Gelato**.

**From the customer portal**

Customers can visit ``/my/print-orders`` to view their orders and submit new
ones at ``/my/print-orders/new``.

Known issues / Road map
-----------------------

* Gelato does not provide a dedicated sandbox URL; use a test API key to avoid
  real charges during development.
* Per-company sequences must be created manually for multi-company setups
  (see *Settings › Technical › Sequences*, code ``gelato.print.order``).
